# 06. Похідні дані: підсумки і фільтри

Рівень: ★★☆ · Ціль: 15 хв

Тут часто виникає плутанина: картки «Отримано / Відправлено / Баланс» це агрегати
по ВСІХ переказах, а не поля одного переказу. Наживо на це легко витратити пів співбесіди.

## Завдання

Завантаження вже написане (`useTransfersAndRates` у `Task.tsx`), фокус тільки на даних.

1. Картки:
   - «Отримано»: сума `incoming` зі статусом `completed`, у гривнях;
   - «Відправлено»: сума `outgoing` зі статусом `completed`, у гривнях;
   - «Баланс»: різниця.
2. Фільтри над таблицею: статус (усі / completed / pending / failed) і напрямок
   (усі / вхідні / вихідні). Таблиця показує тільки відфільтровані.
3. У селекті статусу кількість: «completed (18)».
4. Картки рахуються по ВСІХ переказах, фільтр на них не впливає.
5. Під таблицею «Показано N з M».

## Вимоги

- Тільки ДВА нових useState: значення двох фільтрів. Відфільтрований список і підсумки
  обчислюються під час рендеру (`useMemo` за бажанням).
- **Ніяких** `useEffect(() => setFiltered(...), [filter])`. Це антипатерн, його ловлять на співбесідах.
- Рахувати в цілих копійках, ділити на 100 тільки при виводі.

## Перевірка

Очікувані підсумки: отримано **36 100,00 грн**, відправлено **22 700,90 грн**, баланс **13 399,10 грн**.

## Питання до себе перед кодом

Подивись на кожне число у верстці й назви вголос, звідки воно береться. Якщо незрозуміло,
на співбесіді це питання до інтерв'юера, а не здогадка.
