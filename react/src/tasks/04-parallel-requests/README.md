# 04. Паралельні запити: перекази + курси

Рівень: ★★☆ · Ціль: 15 хв

## Завдання

Заміни захардкожені рядки таблиці на дані з двох ендпоінтів:

- `GET /api/transfers` → `{ items: Transfer[], total }` (~700 мс)
- `GET /api/rates` → `{ base: 'UAH', rates: { UAH: 1, USD: 41.32, ... }, updatedAt }` (~1500 мс)

Вони незалежні, тому запити мають іти **паралельно**.

## Вимоги

1. Обидва запити стартують одночасно. Перевір у Network → Waterfall: смужки починаються разом.
2. Колонка «Сума»: сума у валюті переказу, знак `+` для `incoming`, `−` для `outgoing`.
3. Колонка «В UAH»: `amount × rates[currency]`, округлити до копійки, вивести в гривнях.
4. Дата через `Intl.DateTimeFormat('uk-UA', ...)`, гроші через `Intl.NumberFormat`.
5. Під таблицею «Курс оновлено: <дата>» з `updatedAt`.
6. Один стан-union для обох відповідей. Loading, поки не прийшли ОБИДВІ. Error, якщо впала будь-яка.
7. Abort і cleanup.

## Перевірка

- Час до рендеру ~1.5 с (паралельно), а не ~2.2 с (послідовно).
- `tr_023` (250 USD): «В UAH» показує +10 330,00 грн.
- Додай `?fail=1` до rates: має бути помилка, а не напівпорожня таблиця.

## Пастки

- `amount` у мінімальних одиницях: ділити на 100 тільки при виводі.
- Курс «скільки гривень за 1 одиницю»: множити, не ділити.
- Два `await` поспіль це послідовно, навіть якщо вони в різних рядках «поруч».

## Follow-up питання

- «Що, якщо rates впаде? Показати перекази без колонки UAH?» (часткова деградація,
  `Promise.allSettled`)
- «Як зробити це на React Query?» (`useQueries`)
