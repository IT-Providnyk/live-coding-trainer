# 02. Bug hunt: код, написаний наживо

Рівень: ★★☆ · Ціль: 15 хв

`Task.tsx` це код, який типово пишуть наживо під тиском часу, підключений до
`/api/transfers` цього тренажера. Він компілюється, але на екрані порожньо, і помилки
ніколи не показуються.

## Завдання

1. **Не запускаючи**, прочитай код і випиши в коментар зверху файлу всі проблеми, які бачиш.
   Їх щонайменше 10: від критичних (дані не показуються) до дрібних (якість коду).
2. Біля кожної проблеми познач: критична / важлива / дрібна.
3. Тепер виправ. Результат: таблиця з усіма переказами, суми в гривнях/валюті переказу через
   `Intl`, працюють loading і error (`?fail=1`).
4. Порівняй свій список із розбором у `Solution.tsx`.

## Навіщо

Читати чужий (і свій) код з багами це окремий формат співбесіди («ось PR, що з ним не так?»).
А ще після цієї задачі ти точно не повториш ці помилки наживо.
