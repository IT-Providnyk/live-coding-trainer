# JS-тренажер: чисті функції для live coding

18 задач на чистий JavaScript, без залежностей. Кожна задача: умова, тести, еталонне рішення з розбором.
Задачі тренують те, що найчастіше ламається на live coding: async/await, Promise, обробка
даних з API (дублікати, join за id, копійки, курси), `fetch` з `res.ok`, AbortSignal.

## Як працювати

Потрібен Node.js 22+. Нічого встановлювати не треба.

```bash
cd js
node run.js 03              # тести задачі 03 на ТВОЄМУ коді (tasks/03-*.js)
node run.js 03 07           # кілька задач
node run.js                 # усі
node run.js 03 --solution   # ті самі тести на еталоні (solutions/)
```

1. Відкрий `tasks/NN-*.js`. Умова в коментарі зверху, нижче заготовка функції.
2. Засічи час (ціль указана в умові). Пиши так, ніби поруч сидить інтерв'юер: спершу 30 секунд
   плану вголос, потім код.
3. `node run.js NN`. Тести можна читати, вони теж частина умови.
4. Тільки після цього відкривай `solutions/NN-*.js` і розбір унизу файлу. Порівняй підхід,
   а не лише результат.
5. Через кілька днів повтори задачу з нуля: `git checkout tasks/NN-*.js` поверне заготовку.

Правило: якщо застряг на 10+ хвилин, подивись розбір, закрий його і напиши з нуля.

## Порядок, якщо часу мало

Найважливіше перед співбесідою: **17 → 12 → 14 → 18 → 04 → 05 → 06**. Це те, що в типовій
задачі з API треба встигнути за перші 15 хвилин. Решта задач для загальної форми й типових
JS-питань (debounce, deepEqual, EventEmitter часто дають окремо від React).

## План

Спільний план на 2 тижні для JS і React лежить у `../react/README.md`. Коротко:
2–3 JS-задачі на день поруч з однією React-задачею. JS-задачі дають «цеглинки», React-задачі
збирають з них компонент.

## Для інтерв'юера / ментора

Будь-яку задачу можна дати як пробну співбесіду на 15–20 хвилин: кандидат бачить тільки
`tasks/NN-*.js`, інтерв'юер тримає `solutions/` і розбір. Розбір унизу кожного рішення містить follow-up питання.
